# EP42 — ป่าหมอกสุริยะและคมมีดไร้เงาในความมืด

*The Solar Mist Forest, the Invisible Blade and Memories of Parents* · ต้นฉบับ: `source/Chapter_42_The_Solar_Mist_Forest_The_Invisible_Blade_And_Memories_Of_Parents.md`

เวเลนนำหนีข้ามสะพานหินอ่อน สัญญาว่าจะเล่าเรื่องพ่อแม่ของเรย์เมื่อพ้นอันตราย — หญิงสาวล่องหนปาดคอแนวทหาร เวเลนยิงลำแสงจากปลายนิ้วเจาะประตูเหล็กหนาสามฟุตและเสาม่านพลัง ทั้งหมดหนีเข้าป่าหมอกสุริยะที่รบกวนเรดาร์ ฝูงสุนัขล่าเนื้อเกราะแสงสิบสองตัวถูกกำจัดอย่างเงียบเชียบในสิบห้าวินาที แล้วมุ่งไปยังทางลับเพียงแห่งเดียวสู่โลกเบื้องล่าง

**ภาพ/มุมกล้อง:** เปิดตอน: ไซเรนแดงสะท้อนทั่วหุบเหวเมฆา สปอตไลต์นับร้อยหมุนกวาดราวดวงตาสัตว์ร้าย — เวเลนผมเงินหม่นก้าวนำบนสะพานอย่างมั่นคงไร้ความตื่นตระหนก

- ตะโกน (velen): ตามอาให้ทัน อย่าแตกแถว และอย่าหยุดวิ่งเด็ดขาด!

- ตะโกน (rey): คุณอาเวเลนครับ! เรื่องของคุณพ่อกับคุณแม่ผม... ตอนนี้พวกท่านอยู่ที่ไหนกันแน่ครับ?!

- พูด (rey): เข้าใจแล้วครับ!
