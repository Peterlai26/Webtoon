# EP43 — โพรงรากพฤกษาโบราณ และการฝ่าด่านสกัดสู่โลกเบื้องล่าง

*The Index Beam vs the Light Lance and the Dragon's Fangs* · ต้นฉบับ: `source/Chapter_43_The_Index_Beam_Vs_Light_Lance_And_The_Dragons_Fangs.md`

หุบเหวน้ำตกรากพฤกษา — แม่น้ำดิ่งลงปล่องรากไม้กลวงที่ทะลุก้นเกาะลอยฟ้าลงสู่โลกเบื้องล่าง แต่หน่วยสกัดกั้นของโซลาริสกำลังขึงตาข่ายเลเซอร์ปิดปากปล่อง เรย์แบ่งทีมพังเสาเลเซอร์ทั้งสี่ เวเลนยิงป้อมปืนเรือเหาะพังในห้าวินาที หญิงสาวล่องหนทำลายแผงควบคุม ทั้งแปดกระโดดลงปล่อง และเวเลนยิงหินผาถล่มปิดทางไล่ล่าไว้เบื้องบน
