ทุกครั้งที่ตัวละครปรากฏใน Panel ใด ระบบจะดึงนิยามเดียวกันนี้มาวาด จึงไม่มีการ "เปลี่ยนหน้า" ระหว่างตอน

## ข้อมูลอ้างอิงจากต้นฉบับ (เฉพาะที่ระบุไว้)

| ตัวละคร | ข้อมูลจากต้นฉบับ (บท) | ส่วนที่เป็นการออกแบบเพิ่ม (รออนุมัติ) |
|---|---|---|
| **เรย์** | อายุ 19, ผมดำสนิท, ตาแดงสด, แจ็กเก็ตขาวแถบดำเส้นแดงเข้ม (1); ผู้สมัคร 499 (1) | กางเกงเทาเข้ม รองเท้าดำ |
| **ลูคัส** | สูงโปร่ง ผมขาวเงิน ตาฟ้าคม เกราะขาวตัดดำ ลายทอง แสงฟ้าอมเขียว หอกพลังงานทองรูปเรขาคณิต (1, 4, 8) | รายละเอียดชิ้นเกราะ |
| **เซร่า** | ผมดำยาวปิดตาหนึ่งข้าง (2) — ตาขวาพ้นผม (9), ชุดต่อสู้ดำรัดรูป, ดาบยาว, แขนถอดได้ด้วยเส้นใยแดง (2), ตาสีเข้ม (9) | ตาสีน้ำตาลเข้มเกือบดำ |
| **ลิลิธ** | ร่างเพรียว เสื้อกาวน์ขาวตัวยาว ผมสีเข้มยุ่ง แว่นกรอบบาง เคี้ยวลูกอม (3); เสื้อคลุมสีเข้มทับกาวน์ (4); ถุงมือยางดำ (9) | สีผมน้ำตาลเข้ม, ตาสีเขียวหม่น |
| **แอช** | โค้ทปะชุนหลากสีพันโซ่ เกราะหนามบนไหล่ กระสอบใหญ่ หน้ากากกะโหลกขาวลายแดง ผิวเขียวอมเหลืองมีรอยเย็บ มือพันผ้าสกปรก (4); แขนเกราะหิน (7) | หัวไม่มีผม (ต้นฉบับไม่ระบุ) |
| **เนลล์** | สูงโปร่ง โค้ทยาวดำแถบเงิน-น้ำเงิน ผมน้ำเงินเข้มเกือบดำปลายขาวเงิน ตาอำพัน ตะเกียงเปลวม่วงฟ้า ระฆังมือ สมุดหนัง ถุงมือดำ ปากกาขนนก (5) | — |
| **แลตช์** | สูงผอม ยูนิฟอร์มแดงเลือดหมู กระดุมทองสองแถว ลายรูกุญแจทองที่คอปก หมวกทรงกลม ถุงมือขาว ผิวเข้มคล้ำ ตาเรืองแสงขาวไร้รูม่านตา ปืนทองเหลืองไกรูปกุญแจ ลูกกุญแจยักษ์ปลายเรืองแสง (6) | — |
| **มาดามซูเจอร์** | สตรีอาวุโส ผมดำครึ่งขาวครึ่ง แว่นกรอบบาง ปากดำคล้ำ ชุดหนังดำคล้ายผ้ากันเปื้อนศัลยแพทย์ รอยเย็บที่เอว เกราะไหล่ บูทส้นสูงหุ้มเกราะถึงต้นขา นิ้วติดใบมีด/เข็มเงิน ด้ายเงิน (6) | สีตาแดงเข้ม |
| **วิคาร์ เวล** | เกราะขาว-ดำร่องรอยการศึก ผ้าคลุมขาดวิ่น วงแหวนแสงทองแตกเหนือหมวก ตาม่วงเรืองใต้หน้ากาก ผมขาวยาว ดาบแสงม่วงอมชมพู (6, 8) | สีผ้าคลุม (เทาเข้ม) |
| **ราเซ่** | ร่างสูงเพรียว โค้ทมีฮู้ดดำหนังเกรดทหาร สายรัด/หัวเข็มขัดโลหะ ผมดำสั้นระต้นคอ ตาแดงฉาน หน้ากากครอบกรามโลหะขาวช่องระบายเฉียง ใบมีดโค้งคล้ายเขี้ยว+เคียวที่แขนขวา ตะขอโซ่ (10) | — |
| **ผู้คุมสอบ** | วัยกลางคน หน้าดุ แผลเป็นพาดคิ้ว ปืนพลังงานที่เอว (1) | ผมสั้นเทาเข้ม, ชุดขาว-ทอง |
| **ผู้ชำระล้าง** | เกราะเบาขาว-เงิน ตราดวงอาทิตย์ ไรเฟิลแสงลำกล้องขาว (2) | หมวกปิดหน้า |
| **ไนท์แฟงก์** | โค้ทหนังดำ ตราเขี้ยวสีเลือด (7) / เขี้ยวสีเงิน (9–10) | ใบหน้า |
| **ลุงเกรย์** | วัยกลางคนกำยำ เสื้อกั๊กหนังเย็บปะ มือซ้ายแช่น้ำแข็งในถุง (3) | ผมสั้นน้ำตาล |
| **อันเดดตาบอด** | ร่างมนุษย์ถูกยืด ผิวเทาอมฟ้า แผลเป็น เศษผ้า แขนขายาวกรงเล็บ ตาขาวขุ่น ขากรรไกรฉีกถึงหู ฟันนับสิบ (5) | — |

ตัวละครที่ต้นฉบับไม่ได้บรรยายรูปลักษณ์ (เจ้าหน้าที่ทั่วไป ผู้สมัครอื่น นักวิเคราะห์ ฯลฯ) ใช้แบบกลางๆ และไม่ได้รับบทพูดหรือบทบาทเพิ่มเติม
