## ข้อจำกัดที่ทราบ (ไม่ได้ซ่อนไว้)
1. **คุณภาพภาพ**: สไตล์แฟลตจากเอนจินเวกเตอร์ ท่าทางบางช่องแข็ง/ฉากแอ็กชันอ่านยากกว่างานวาดมือ บางช่ององค์ประกอบยังไม่สวย (เช่น ตัวละครถูกตัดขอบ)
2. **กล่องข้อความในช่องที่บทยาว** อาจบังตัวละครบางส่วน (ไม่ทับกันเองและไม่ล้นขอบ) — ปรับรายช่องได้ใน Admin
3. ต้นฉบับมีความไม่สอดคล้อง 14 จุดที่ต้องให้เจ้าของผลงานยืนยัน
4. รายละเอียดรูปลักษณ์ที่ต้นฉบับไม่ระบุ (เช่น กางเกงของเรย์) เป็นการออกแบบเพิ่มที่ระบุไว้ใน `02-character-reference.md` เพื่อรออนุมัติ
5. File storage เป็นดิสก์ภายในเครื่อง — เหมาะกับเว็บไซต์ส่วนตัวเครื่องเดียว; หากต้องการหลายเครื่องควรเพิ่ม adapter object storage
